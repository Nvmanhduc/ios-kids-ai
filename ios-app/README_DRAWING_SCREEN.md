# Drawing Screen (SwiftUI + PencilKit)

## Files
- KidsAIColoringApp.swift
- DrawingHomeView.swift
- DrawingCanvasView.swift
- PencilCanvasRepresentable.swift
- DrawingViewModel.swift

## Quick setup in Xcode
1. Create new iOS App project (SwiftUI) named `KidsAIColoring`.
2. Copy all files from `ios-app/KidsAIColoring/` into project.
3. Ensure deployment target iOS 16+.
4. Run on iPhone/iPad simulator or device.

## What is included
- Canvas drawing with PencilKit
- Brush / eraser toggle
- Stroke width slider
- Undo / redo
- Clear canvas
- Export image preview flow hook
